# NextCode 3.18.0

首个以 **NextCode** 名义发布的 Windows 安装包。基于 ZCode 开源版（上游基线 commit `872ad96`，版本 3.14.0）
改造的内部定制版，**沿用原项目的 Apache-2.0 许可**，不代表上游项目。

## 安装 / 升级注意

- **appId 已变更**（`dev.nextcode.app`）：本版与旧的 `ZCode 3.16.x / 3.17.x` 在 Windows 上是**两个独立应用**，
  可以并排安装、互不覆盖。建议先卸载旧版再装本版，避免快捷方式指错程序。
- 清理更新缓存：删除 `%LOCALAPPDATA%\@zcodedesktop-updater\`（定制版已关闭官方更新，残留缓存不会执行，
  清掉只为避免误判）。
- 设置与会话数据仍在 `~/.zcode`，**不受改名影响**；命令行命令仍为 `zcode`。

## 本版改动

### 品牌与身份

- 产品名、安装包名、appId/AUMID、Windows/Linux 可执行名统一改为 **NextCode**；界面文案、网页标题、
  关于窗口、托盘提示与分享页品牌同步（zh/en 各 113 处）。
- Logo 与全部图片换成同风格的「N」标记（沿用原型 Z 的笔重比例、斜度与圆角交界过渡）：
  应用图标 9 个尺寸 + ICO 7 尺寸、安装器 3D 盒子图标、启动徽标、草稿水印、README 展示图标。
- 内部标识（`@zcode/*` 包名、`ZCODE_*` 环境变量、`zcode` 命令、`zcode-protocol`、`~/.zcode` 数据目录）
  刻意保留，以兼容上游代码与既有数据。

### 去掉官方通道与外部依赖

- 关闭官方渠道自动更新与强制升级（首版定制包曾被官方后端强制升级覆盖，已修正）。
- 遥测编译期硬关断，并删除遥测 SDK 依赖与 11 个相关模块（随包不再含该 SDK）。
- 远程工作区运行时资源随安装包分发并本地优先，**离线或不通外网也能连接远程工作区**，
  不再出现 `manifest not found for linux-x64` 类失败。
- 移除官方渠道入口：产品文档、用户社群、问题上报、给产品提需求、检查更新
  （帮助菜单、命令面板、托盘菜单与 macOS 原生菜单一并清理，不留"菜单里没了、面板还能打开"的入口）。

### 安全与卫生

- Web 服务与手机端访问补齐响应安全头：`nosniff`、`no-referrer`（二维码 URL 带 token）、
  `X-Frame-Options: DENY`、收敛的 `Permissions-Policy`，以及 HTML 的 CSP（脚本仅限本服务 +
  内联脚本 sha256、允许 WebAssembly 编译、`object-src 'none'`、`frame-ancestors 'none'`）。
- 死代码与依赖清理（9 个无调用方模块 + 遥测 SDK），并修掉"陈旧 `node_modules` 残留会被打进安装包"
  的问题；安装包体积随之下降。
- i18n 死键检查与清理工具（`pnpm i18n:dead-keys` / `pnpm i18n:prune-dead-keys`），首轮清理 410 键/语言。

### 功能新增与增强

- **提示词增强**：输入框发送按钮旁新增增强按钮，用当前选中的模型配置润色草稿并替换。
- **侧栏项目置顶与揭示**：切换到某个项目时自动把它移到列表顶部并滚动到可见位置。
- **手机端访问**：用户名旁手机图标进入控制面板，开关服务、可选内网 IP、展示二维码；开启后图标变绿。
  **仅在局域网内可达，不支持公网访问**，服务只在用户选择的局域网地址监听，不做端口映射或内网穿透。
- **手机/窄视口适配**：侧栏变覆盖式抽屉并默认收起、任务列表使用不透明背景，手机浏览器不再是桌面布局。
- **主题**：新增「黑客」主题（黑底绿字、保留语义色相）；主题选项收敛为单一来源，设置页与侧栏菜单一致。

### 修复

- 侧栏项目揭示失效（`data-testid` 中 Windows 路径的反斜杠被当作 CSS 转义）。
- 提示词增强点击即报错（进程内 `AbortSignal` 无法跨渲染层边界）。
- 手机端：手机图标状态色不随服务变化、任务列表抽屉背景透明。
- SSH 远程连接报 `manifest not found for linux-x64`（打包态未把随包资源目录传给远程部署）。
- 设置页主题下拉框看不到 Zai/黑客主题（界面主题存在两份硬编码列表，且标签文案不可区分）。
- CSP 缺 `'wasm-unsafe-eval'` 导致 diff 高亮与 Office 预览的 wasm 编译被拦。
- 渲染层启动徽标与关于窗口仍显示旧字形（内联字形有 5 处副本，现已加防漏校验）。

## 已知限制

- 手机端访问**只支持局域网**：手机需与电脑处于同一网络（同一 Wi-Fi/网段），不支持公网访问。
- macOS 专用资产（`icon.icns`、`icon_installer.icns`、DMG 背景图）尚未替换；本版只提供 Windows x64 安装包。
- 命令行命令仍为 `zcode`，数据目录仍为 `~/.zcode`（内部标识未纳入本次改名）。
