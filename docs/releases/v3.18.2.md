# NextCode 3.18.2

主题：**对话体验稳定性 + 第三方模型接入**——修掉对话页抖动与模型切换提示误报，
打通 OpenCode Go 订阅端点，并新增流式 token 速率显示。
基于 ZCode 开源版（上游基线 commit `872ad96`）改造的定制版，沿用 Apache-2.0 许可。

## 修复

### 对话页抖动

长时间会话中对话列表间歇性整体闪动/跳动。根因是跨端刷新链路把**整快照**下发给 UI，
快照「整体替换、绝不 merge」的语义让所有行的对象引用全部更换，React 记忆化失效、
整个列表重渲染。三层修复（specs/web-mobile-cross-process-sync.md 第四阶段）：

- UI 快照按 rowId 保持未变行的对象引用（深度浅比较门控），内容未变的行不再重渲染；
- 跨进程 refresh 增加内容指纹门控：本进程有活跃 turn 的会话不做整帧重水合，
  指纹未变化的会话不重发快照（重水合成功后才提交新指纹）；
- 冷合并告警日志降级，消除生产日志刷屏。

端到端验证：静置 5 秒收到快照帧数为 0（修复前 82 秒内 38 次整快照重水合）。

### 模型切换提示误报

- 重新选择**当前已在用**的模型时不再弹「模型已切换 A → B」提示、不再插入切换标记行
  （渲染标签相同即判定为冗余切换）。
- 同一模型经不同供应商身份选择导致的重复提示一并抑制。

### OpenCode Go 会话头

第三方供应商指向 OpenCode Go 端点时，base URL 少写 `/v1`（如 `https://opencode.ai/zen/go`）
会静默丢失 `x-opencode-session` 头，Go 网关以 400 拒绝、界面只显示「Provider rejected the
model request」。现在判定与 anthropic baseURL 归一化对齐（`/zen/go` 与 `/zen/go/v1` 均视为
Go 端点），配置少写 `/v1` 也能正常工作（specs/opencode-go-session-header.md）。

## 新增：流式 token 速率显示

- 模型流式输出期间，输入框上方实时显示当前回复的生成速率（≈ N token/s），
  悬停可见已生成 token 数与耗时；回复结束立即消失，不影响布局。
- 速率为启发式估算（流式帧不携带逐帧真值 usage）：中文 ≈ 0.6 token/字符、
  其它 ≈ 1 token/4 字符；按当前 model response 的正文+思考行累计平均计算，
  流停顿时数字按时间自然回落（specs/streaming-token-rate.md）。

## 已知限制

- token 速率为**估算值**（以「≈」标示），非 provider 真值。
- 手机端访问仍**仅限局域网**，不支持公网。
- macOS 安装包仍未提供；命令行命令仍为 `zcode`，数据目录仍为 `~/.zcode`。
